# دليل تشغيل العتاد — من T4 إلى RTX 4090 وأعلى

## أهداف زمن نقطة `clone_voice_and_mix` بعد التطبيق الكامل (نص هدف ≈10 ثوانٍ صوت)

| فئة الكرت | الهدف الملزم | هدف التميز | إعدادا العمال | ملاحظات |
|---|---|---|---|---|
| T4 / RTX 3050 (8GB) | ≤ 5.5s | ≤ 4.5s | `VM_EXECUTOR_WORKERS=1` | bf16 غير مدعوم → fp16 تلقائي؛ فعّل `VM_ECAPA_DEVICE=cpu` إن ضاقت الذاكرة |
| RTX 3060 / 4060Ti (12–16GB) | ≤ 4.0s | ≤ 3.0s | `VM_EXECUTOR_WORKERS=2` | bf16 مفعل تلقائياً |
| RTX 3090 / 4070 (24GB) | ≤ 2.8s | ≤ 2.2s | `VM_EXECUTOR_WORKERS=2` | جرّب `VM_COMPILE=on` |
| RTX 4080 / 4090 | ≤ 2.0s | ≤ 1.5s | `VM_EXECUTOR_WORKERS=2` | `VM_COMPILE=on` موصى به بعد اختبار الاستقرار |
| 5090 / A100 / H100 | ≤ 1.4s | ≤ 1.0s | `VM_EXECUTOR_WORKERS=2–3` | وثّق أرقامك؛ أضف طلبات متزامنة عبر طوابير |

## أوامر نظام التشغيل (تُنفذ بشرياً قبل التشغيل — لا من الكود)

```bash
# وضع الاستمرار (يلغي 0.2–0.6s من أول طلب بعد خمول الكرت)
sudo nvidia-smi -pm 1

# تثبيت ساعات النوى على القيمة العليا (استبدل 2595 بقيمة Max Clock لكرتك من nvidia-smi -q)
sudo nvidia-smi -lgc 2595,2595 -i 0

# التحقق أثناء الحمل (الساعات الفعلية واستخدام النوى)
nvidia-smi dmon -s pucvmet
```

## CUDA MPS (متعدد العمليات على كرت واحد)

يفيد عند تشغيل ECAPA/Whisper/الخادم كعمليات منفصلة — يقلص تداخل السياقات:

```bash
nvidia-cuda-mps-control -d        # بدء الخفي (root)
# ثم شغّل الخدمة كالمعتاد — العملاء يتصلون تلقائياً عبر MPS
echo quit | nvidia-cuda-mps-control   # الإيقاف
```

اختبر قبل اعتماده: قارن P99 لـ 100 طلب مع/بدونه؛ لا تفعّله إن لم يظهر مكسب.

## uvicorn مع uvloop

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --loop uvloop --http httptools
```

(المكونان ضمن `uvicorn[standard]` المثبت أصلاً — علم `VM_UVLOOP` توثيقي لتذكير فريق التشغيل.)

## قواعد الذاكرة

- النموذج (bf16) ≈ 4GB + سياق التوليد 2–6GB حسب طول النص → حدّد `VM_EXECUTOR_WORKERS` بحيث لا يفوق الطلبان المتزامنان VRAM.
- مؤشر سريع: `nvidia-smi --query-gpu=memory.used,memory.total --format=csv -l 5` أثناء ضغط مزدوج.
- tmpfs (`/dev/shm/voxmixer`) يحمل الملفات الوسيطة في RAM — تأكد من توفر ≥1GB حرة (يتراجع تلقائياً للقرص وإلا).
